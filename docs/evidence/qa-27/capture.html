Owner steps: first live sends

Nothing is sent until you reply go.

Telegram — issue #10

  1. Use $HOME/.config/pi-hermes-gateway/pilot as the profile directory.
  2. In its config.json, fill adapter.config.token and routes[0].chatId with your private values.
  3. Set the config file permissions: chmod 600 "$HOME/.config/pi-hermes-gateway/pilot/config.json".
  4. Check the profile: 
    PROFILE="$HOME/.config/pi-hermes-gateway/pilot"
pi-hermes-gateway-core --profile "$PROFILE" doctor
  5. Reply go when ready. Keep the token and chat ID private.

WhatsApp — issue #12, after Telegram

  1. Use the separate profile $HOME/.config/pi-hermes-gateway/whatsapp-pilot.
  2. As owner, pair a fresh linked device into its whatsapp-auth folder using the provider's QR or one-time-code flow.
  3. Put your recipient JID in routes[0].chatId in that profile's private config.json.
  4. Unofficial automation or linked devices can risk account restriction or a ban; proceed only if you accept that risk.
  5. Check the profile: 
    PROFILE="$HOME/.config/pi-hermes-gateway/whatsapp-pilot"
pi-hermes-gateway-core --profile "$PROFILE" doctor
  6. Reply go when ready. Keep the JID private.
